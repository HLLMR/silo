# Silo on TikTok + Instagram

> A hook-first short-form playbook for Silo on TikTok + IG Reels: repeatable "which mod crashed you" screen-capture formats, a realistic cadence, first-week clips, and the Claude/Cowork skills to run it semi-autonomously.

## TikTok + Instagram Reels

### Why this platform fits Silo

Silo's core promise is a *feeling* before it's a feature: the specific rage of a 300-mod FS25 save that crashes on load and won't tell you why. That is a perfect short-form hook — visual, emotional, universally shared by the audience, and resolved in under 15 seconds. TikTok and IG Reels reward exactly the thing Silo can do organically: **show the pain, show the one-click fix, cut.** No account needed to try it, nothing to sell, so every clip is a clean "here's a free tool that ends this specific misery."

FS25's audience is bimodal, and short-form is where the *casual majority* actually live. The GitHub/Reddit tech minority will find Silo through docs and threads; the Facebook-group farmer and the teenage "I just want my mods to work" player scroll Reels and TikTok. This is the top-of-funnel channel that reaches people who would never read a changelog.

**Who we reach here:** FS25 players who mod but aren't technical, younger players (14–25) who found FS through YouTubers/streamers, and mod-curious lurkers. Secondary: FS content creators who might feature Silo in their own videos (clip-able moments are shareable assets for them too).

**Voice for THIS platform:** This is the one channel where the gen-Z energy is the whole point, not a garnish. First-person POV, meme cadence, on-screen captions doing the heavy lifting (most watch muted), trending sounds used *tastefully* and only when they actually fit the beat. Dry wit over hype. Never corporate, never "revolutionary." The tool is the flex — let the screen recording talk. Always disclose it's the dev ("I made this because it kept happening to me"). Founder-in-public honesty > brand account polish.

### Content pillars

1. **Pain → Fix (flagship, ~50%)** — POV clip opens on the exact frustration (black loading screen, cryptic `log.txt`, "no mods will load"), then Silo resolves it in one motion. Every video is a self-contained rescue.
2. **Feature-in-15 (~20%)** — one crisp capability, screen-recorded, no fluff: conflict catch before launch, "latest version across ModHub+GitHub+Nexus," provenance Verified/Modified badge, the sugar-beet filltype bridge, guided bisection.
3. **Dev-in-public / behind the build (~15%)** — honest solo-dev energy: "someone reported this crash, here's me fixing it live," roadmap teases, "why I don't take your data." Builds the trust the provenance feature trades on.
4. **Community / reactive (~15%)** — duet/stitch a "my game won't launch" FS post with the fix, reply-to-comment videos, "you asked if it works on a 900-mod save — let's find out."

### Cadence (realistic for a solo/small dev)

- **Launch week:** 1 clip/day (7 clips) — front-load the pins + best formats.
- **Sustaining:** 3–4 clips/week TikTok, all cross-posted to IG Reels (batch-film weekly, schedule ahead). 1–2 Stories/week on IG (polls, "what should I fix next," reshared comments).
- **Batch model:** one 2–3h filming/capture block per week produces the week's clips; the Claude skills below turn that raw capture + the changelog into captioned, queued drafts so daily posting isn't daily *work*.
- **Cross-post rule:** film vertical 9:16, keep captions inside IG/TikTok safe zones, and **strip the TikTok watermark before uploading to Reels** (IG suppresses watermarked reposts) — re-export clean from the source capture, don't download-from-TikTok.

### Claude skills to build

Automations a Claude Code / Cowork agent builds so this channel runs semi-autonomously. Every one **drafts and queues for a human to approve and post** — nothing here auto-publishes, auto-DMs, or auto-comments without a human in the loop.

**1. `shortform-changelog-to-script`**
- **What it does:** Reads a new GitHub release (tag, notes, closed issues/PRs since last tag) and turns the most demo-able change into a 15–25s short-form *script*: hook line, 3–5 on-screen caption beats, screen-capture shot list, suggested trending-sound *type* (not a specific copyrighted track — leaves sound selection to the human), and both a TikTok and an IG Reels caption + hashtag set.
- **Trigger:** on new GitHub release (`HLLMR/silo`), plus manual invoke.
- **Inputs:** release notes, diff summary, product feature glossary (from CLAUDE.md), the hook bank.
- **Outputs:** a markdown script file + a draft row in the content queue (see skill 3).

**2. `clip-cutter`**
- **What it does:** Takes a raw screen-capture (and optional talking-head take), a shot list from skill 1, and auto-produces a rough 9:16 cut: trims dead air, zooms/crops to the UI region of interest per beat, burns in the caption beats with the Silo caption style, adds the <1s branded intro frame, and exports a clean **watermark-free** master + a TikTok and IG variant. Flags where a human should drop the sound.
- **Trigger:** on new capture file dropped in `content/raw/`, or manual.
- **Inputs:** raw video, shot list + caption beats, brand style tokens (green/gold, fonts from landing page), safe-zone template.
- **Outputs:** edited draft `.mp4`(s) + a preview thumbnail, attached to the queue row. (Uses ffmpeg + a caption/subtitle renderer; no external upload.)

**3. `content-queue-scheduler`**
- **What it does:** Maintains a single source-of-truth content calendar (Notion or a repo `content/queue.md`). Slots approved drafts into the cadence, avoids clustering the same pillar, holds a "reactive slot" open each week, and produces a daily "here's today's post + caption, approve/skip" digest for the human. Does **not** publish — it hands the human the ready-to-upload file + caption at post time (or preps a scheduler like Meta Business Suite/TikTok's native scheduler where API-permitted).
- **Trigger:** weekly (plan the week) + daily (surface today's card).
- **Inputs:** approved drafts, cadence config, pillar mix targets, past-post log.
- **Outputs:** updated calendar, daily approval digest, per-post upload package (video + caption + hashtags + first-comment link text).

**4. `comment-triage-assistant`**
- **What it does:** Pulls new comments/DMs (via each platform's official API/inbox export), classifies them — bug report, feature request, "does it do X," praise, troll, support — and drafts honest, on-voice replies for the human to approve/send. Routes genuine bug reports into a GitHub issue draft. Surfaces high-signal praise as candidate Highlights/reshares (with a permission-ask template). Never auto-sends; never mass-DMs; flags anything it shouldn't answer (security/provenance claims) for the human.
- **Trigger:** daily, or on-demand after a clip pops off.
- **Inputs:** comment/DM export, product FAQ, tone guide, known-issues list.
- **Outputs:** a triage board (reply-drafts by category), GitHub issue drafts, reshare candidates + permission-request drafts.

**5. `trend-scout` (advisory only)**
- **What it does:** Weekly, surfaces currently-rising short-form *formats and audio trend patterns* relevant to gaming/tech/"POV problem→fix," and proposes 2–3 ways to map an upcoming Silo beat onto them — tastefully, with a "does this actually fit? y/n" gut-check note. Advisory input to skill 1; it never fabricates engagement or buys anything.
- **Trigger:** weekly.
- **Inputs:** platform trend signals (human-supplied or via permitted APIs), the roadmap, pillar list.
- **Outputs:** a short "this week's tasteful trend fits" memo feeding the next scripts.

**6. `reactive-stitch-finder`**
- **What it does:** Scans (human-permitted) public FS25 "won't launch / which mod crashed me" posts across Reddit/forums, drafts a respectful stitch/duet/reply concept that leads with genuine help (not a pitch), and queues it into the reactive slot. Enforces: help first, disclose it's the dev, blur names, respect each community's self-promo rules.
- **Trigger:** twice weekly, or on a spike.
- **Inputs:** public post feed, community-rules config, the diagnose demo assets.
- **Outputs:** reactive-clip concept + caption drafts in the queue, with the source link and a rules-check note.

### Metrics that matter here

- **Retention / average watch time & completion rate** — the single most important short-form signal; a strong hook + fast payoff is the whole game. Target: hold ≥ 50% at 3s, and full-watch/rewatch on the <20s clips.
- **Watch-time-weighted reach / "for you" impressions** — are new (non-follower) people seeing it. This is discovery health.
- **Saves + shares** — highest-intent signals here; a "save" on a fix-it clip = someone will need it later. Weight these over likes.
- **Profile visits → link taps → site sessions** (UTM `?ref=tiktok` / `?ref=reels`) → **downloads**. The only metric that ties short-form to actual Silo installs; instrument the landing link so you can see which clip converted.
- **Follower growth rate** (secondary — reach matters more than follower count on these platforms).
- **North-star:** clip → site visit → download conversion, tracked per clip, so you double down on the formats that install the app, not just the ones that go viral.

### Guardrails

- **No astroturfing, no bought views/followers/engagement, no fake accounts, ever.** Growth is earned by the hook or not at all.
- **Disclose it's the dev/community** in origin and reactive clips; disclose AI-assisted editing where a platform's norms expect it (e.g. AI-content labels on TikTok/IG when a clip is substantially AI-generated — captions/edits from the skills above are assistive, but label per each platform's current policy).
- **Sound/music licensing:** use each app's in-app commercial-safe audio library for a business account; don't rip copyrighted tracks that could mute or geoblock the clip. The skills suggest a *sound type*, the human picks a cleared track.
- **Respect community rules on reactive content** — help first, blur names, honor each group/subreddit's self-promo ratio; never brigade or mass-tag.
- **Honesty about claims:** "provenance, not antivirus" — never let a clip imply Silo scans for malware. Reversible/no-telemetry claims must stay literally true.
- **No mass-DMing.** The comment/DM assistant drafts individual, human-approved replies only.

### Effort / priority

- **Priority: HIGH for top-of-funnel reach, MEDIUM for direct conversion.** This is the widest-reach channel to the casual majority but the hardest to attribute to installs — treat it as awareness that feeds the site and Discord.
- **Human effort:** ~3–4 hrs/week once the skills are running (one capture/film block + daily 5-min approvals). Front-loaded launch week is heavier (~6–8 hrs).
- **Build order for the skills:** (1) `shortform-changelog-to-script` and (3) `content-queue-scheduler` first — they unblock consistent posting; (2) `clip-cutter` next (biggest time-saver); then (4) `comment-triage-assistant`; (5) `trend-scout` and (6) `reactive-stitch-finder` last, as reach grows enough to justify them.
- **Lowest-cost highest-return move:** nail the single flagship `#WhichModCrashedYou` format and repeat it with fresh crashes/mods — one proven format beats ten experiments here.
